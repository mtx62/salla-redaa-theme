# حزمة التقديم على متجر ثيمات سلة (Salla Partners Marketplace)
## ثيم: رِداء | Redaa Luxury E-commerce Theme

---

### 1. البيانات الأساسية للثيم (Basic Information)
- **اسم الثيم بالعربية:** ثيم رِداء الفاخر
- **اسم الثيم بالإنجليزية:** Redaa Luxury E-commerce Theme
- **المعرف التقني (Slug):** `redaa`
- **الإصدار الحالي:** `1.0.0`
- **المستودع البرمجي (Repository):** `https://github.com/mtx62/salla-redaa`
- **محرك الثيم:** Salla Twilight Engine 2.0 (React + Vite + Tailwind CSS)
- **الأجهزة المدعومة:** متجاوب بالكامل 100% مع الجوال، التابلت، والديسكتوب (Mobile-First)

---

### 2. النبذة الترويجية الموجزة (Short Tagline)
> **"تجربة تسوق تحاكي كبرى دور الأزياء العالمية بهوية سعودية عصرية راقية.. مصمم خصيصاً لمتاجر العبايات، الأزياء الراقية، العطور، والمجوهرات."**

---

### 3. الوصف الترويجي الكامل (Full Description)
**ثيم "رِداء"** هو ثيم إلكتروني فاخر تم ابتكاره بعناية فائقة ليرتقي بمظهر متجرك الإلكتروني إلى مصاف دور الأزياء العالمية والعلامات التجارية المرموقة. يجمع الثيم بين البساطة الراقية (Minimalist Luxury) والهوية العربية الأصيلة مع تجربة مستخدم استثنائية وسلسة ترفع معدل التحويل (Conversion Rate) وتزيد من ثقة العميل في علامتك التجارية.

صُمم "رِداء" بأحدث تقنيات الويب الحديثة (React 18 و Tailwind CSS) متوافقاً بالكامل مع محرك سلة الجديد **Twilight 2.0**، ليمنح متجرك سرعة تحميل فائقة وتصفحاً فورياً بلا أي تأخير، مع تفاصيل بصرية آسرة تتناغم مع مختلف شاشات الهواتف الذكية.

---

### 4. أبرز المميزات التنافسية للثيم (Key Highlights)
1. **هيدر تحريري عائم سينمائي (Floating Editorial Header):**
   - نافبار شفاف عائم يندمج بانسيابية مع الفيديو الترويجي والبانر الرئيسي.
   - كبسولة زجاجية فاخرة (Frosted Glass Capsule) لاختيار اللغة والعملة تضمن وضوحاً تاماً وقراءة مريحة مع مختلف الخلفيات.
   - قوائم تنقل منسدلة أنيقة ومرنة بدون أي تداخل أو تشويه في العرض.

2. **قناع تموجات عضوية فاخر (Organic Wave Transitions):**
   - فاصل بصري متموج ناعم يربط مقطع الفيديو أو البانر الرئيسي بأقسام المتجر بأناقة حصرية تلفت الأنظار وتمنح المتجر طابعاً حيوياً.

3. **بطاقات منتجات تفاعلية وذكية (Interactive Product Cards):**
   - عرض صور المنتجات بجودة عالية مع تأثير التبديل التلقائي عند التمرير (Hover Image Switch).
   - شارات العروض والتخفيضات الذهبية مع نجوم التقييم المعتمدة.
   - إمكانية الإضافة السريعة للسلة وتحديد الخيارات والمقاسات مباشرة.

4. **سلايدر التقييمات وتجارب العملاء (Social Proof & Testimonials):**
   - مكوّن مخصص لعرض آراء المشترين وتقييماتهم يعزز الثقة ويدعم قرار الشراء الفوري.

5. **فوتر "الجزيرة العائمة" المتكامل للثقة والأمان (Floating Island Footer):**
   - بطاقة بيضاء عائمة معتمة تضم كافة بيانات الموثوقية: شعار المركز السعودي للأعمال (SBC)، الرقم الضريبي (VAT)، وخيارات الدفع الإلكتروني المعتمدة (مدى، Apple Pay، تمارا، تابي، فيزا، ماستركارد).
   - روابط تنقل سريعة وسياسات المتجر مصنفة بوضوح.

6. **أداء تقني استثنائي وتوافق كامل (High Performance):**
   - كود نظيف وخفيف بدون مكتبات زائدة يمنح أعلى درجات في Google Lighthouse و PageSpeed.
   - تجربة استعراض فورية بدون إعادة تحميل الصفحة بفضل معمارية React SPA.
   - دعم كامل للغة العربية (RTL) والإنجليزية (LTR).
